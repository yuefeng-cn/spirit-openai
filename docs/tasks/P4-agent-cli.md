# P4：Agent 与 CLI

## P4-01：注册图片工具并接入会话上下文

### 目标

在 `src/agent.ts` 注册生成和编辑工具；在 `src/index.ts` 中加载当前会话，接收本轮图片，并向本轮 Agent 提供最近普通对话和 `ImageService` 生成的必要图片上下文。

### 约束

- 先登记本轮图片，再判断本轮是否为图片编辑；
- 普通聊天不附带无关图片；
- 图片编辑先解析目标，歧义时让 Agent 反问；
- 成功后输出稳定的 `@img-N`、父图信息和本机图片绝对路径；
- 默认不输出签名 URL，不自动打开图片，也不实现终端内渲染；
- Provider 调用不能直接写在 `agent.ts` 或 `index.ts`；
- CLI 启动需要有简单的新建/恢复会话方式。

### 验收

```bash
npm test
npm run build
```

## P4-02：完成 CLI 回归测试

### 目标

覆盖：上传参考图并编辑 → 输出本机图片路径 → 普通聊天 → 生图 → “刚才这张”编辑 → `@img-N` 选择旧图分支编辑 → 退出并恢复同一会话 → 新会话不带入旧图。

### 验收

```bash
npm test
npm run build
```
